# sf-core-skills

A collection of Salesforce agent skills, modified for GitHub Copilot from
[forcedotcom/sf-skills](https://github.com/forcedotcom/sf-skills).

The skills are industry-agnostic — they apply to any Salesforce implementation
across industry clouds, not to a single product or vertical.

## Skills

| Skill | Description |
| --- | --- |
| `automation-flow-generate` | Generate Salesforce Flows via `execute_metadata_action` |
| `dx-code-analyzer-run` | Run Salesforce Code Analyzer scans |
| `dx-org-analyze` | Analyze and diff Salesforce orgs |
| `experience-lwc-generate` | Generate Lightning Web Components |
| `integration-connectivity-generate` | Generate integration/connectivity artifacts |
| `omnistudio-datamapper-generate` | Generate Omnistudio DataMappers |
| `omnistudio-flexcard-generate` | Generate Omnistudio FlexCards |
| `omnistudio-integration-procedure-generate` | Generate Omnistudio Integration Procedures |
| `omnistudio-omniscript-generate` | Generate Omnistudio OmniScripts |
| `platform-apex-generate` | Generate Apex classes |
| `platform-apex-test-generate` | Generate Apex tests |
| `platform-metadata-api-context-get` | Retrieve Metadata API context |
| `platform-metadata-deploy` | Deploy Salesforce metadata |
| `platform-permission-set-generate` | Generate Permission Sets |
| `platform-sharing-owd-configure` | Configure org-wide defaults |
| `platform-sharing-rules-generate` | Generate sharing rules |
